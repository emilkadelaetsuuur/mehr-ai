# Конфиденциальность и доступ

## Роли

| Роль | Учётка в демо | Что видит и делает |
|------|---------------|--------------------|
| Руководитель | `rahbar` | весь район, показатели врачей, эскалации, журнал аудита, страница DMED, сброс демо-данных |
| Специалист | `mutaxassis` | реестр, задачи «осмотр специалиста», импорт анализов, страница DMED |
| Семейный врач | `shifokor` | свои пациенты и их задачи, события из больниц |
| Медсестра | `hamshira` | визиты, диктовка измерений, приглашения на прививку |

Роль берётся из учётной записи, сервер проверяет её на каждом действии; интерфейс не показывает недоступные кнопки. Пароли хранятся как PBKDF2 с солью, сессия — подписанная cookie, подбор пароля временно блокируется.

## Диспансерные группы

Группы и коды МКБ-10 — в `app/groups.json`:

| Группа | МКБ-10 | Конфиденциальная |
|--------|--------|:----------------:|
| ВИЧ-инфекция | B20–B24, Z21 | да |
| Инфекции, передающиеся половым путём | A50–A64 | да |
| Туберкулёз | A15–A19 | да |
| Хронический вирусный гепатит | B18 | да |
| Сахарный диабет | E10–E14 | нет |
| Артериальная гипертензия | I10–I15 | нет |

Для конфиденциальных групп:

- **Название группы и диагноз** видят только специалист, руководитель и лечащий врач этого пациента. Остальные видят пометку «На диспансерном учёте».
- **В звонке диагноз не звучит.** После имени ИИ спрашивает год рождения; в вопросах — только лекарства, осмотры, самочувствие.
- **В уведомлениях** диагноз не пишется. Журнал обмена с DMED, где диагнозы есть, открыт только руководителю и специалисту.
- **Звонок возможен только после отдельного согласия.** Его записывает сотрудник, которому разрешено видеть диагноз; дата видна в карточке и в реестре, в DMED уходит ресурс `Consent`. Без согласия сервер не создаст звонок (409 `consent`).

## Каждый сценарий — только своему адресату

Сервер проверяет, подходит ли сценарий пациенту, прежде чем создать звонок, и отказывает с 409, если нет. Пациенту на диспансерном учёте не позвонят про детей, а маме здорового ребёнка — про лечение. Приглашение задать вопрос и пункты памятки тоже подбираются под группу пациента.

## Что ещё

- **Согласие на звонки вообще** — без записанного согласия ИИ-звонка нет.
- **Аудит**: каждое изменение данных пациента пишется в `audit_log` с учётной записью, ролью и действием.
- **В языковые модели** не передаются имя, телефон и адрес пациента.
- **Голос не хранится**: запись удаляется после расшифровки.
- **Демо-данные синтетические**; реальных пациентов в системе нет.
