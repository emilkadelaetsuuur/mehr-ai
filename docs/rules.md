# Правила предметной области

Каждое правило закреплено в коде (`app/core.py`, `app/rules.py`) и проверяется тестами (`tests/test_core.py`).

## Зоны риска

- **Зону решают только правила** из `app/rules.json`. Каждая причина показывается со значением, правилом и цитатой из источника. ML-модель — лишь второе мнение рядом.
- **Подняться в зону можно автоматически, спуститься из красной — только после осмотра специалиста.** Даже если пришёл хороший анализ, пациент остаётся в красной зоне, пока открыта задача «Осмотр специалиста».
- **Устаревшие измерения на зону не влияют**: срок годности — 45 дней (`valid_days`).
- Пороги — общий ориентир; окончательные значения утверждает врач по национальному клиническому протоколу.

## Задачи и сроки

- Тревожный признак — задача специалисту или семейному врачу с таймером 24 часа.
- Задача не закрыта вовремя — один раз эскалируется руководителю. Таймеры проверяет планировщик раз в минуту.
- Закрыть задачу может владелец роли (семейный врач — только по своему пациенту) или руководитель.

## Никто не молчит

- 7 дней без связи — жёлтая зона, 14 дней — красная (для беременных, родильниц и новорождённых).
- Три звонка без ответа — задача медсестре сходить домой.

## Двустороннее подтверждение

Врач отметил визит → ИИ спрашивает пациента «приходил ли к вам врач?» → ответ «нет» видит руководитель как расхождение.

## Согласие

- Без записанного согласия ИИ-звонка нет (409 `consent`).
- Для звонков о конфиденциальном диспансерном наблюдении нужно отдельное согласие ([подробно](privacy.md)).

## События из больниц

- Экстренная госпитализация видна лечащему врачу сразу: кого, когда, куда, почему, кто доставил.
- При выписке диагноз записывается в карту, врачу открывается «Активный вызов», на следующий день планируется звонок. Вопросы выбираются по диагнозу: I00–I99 — сердце, J00–J99 — дыхание, O00–O99 — после родов, остальные — общий контроль.

## Календарь прививок

- По дате рождения и записанным прививкам система сама находит детей, которым пора (23 дозы, `app/vaccines.json`; запас — 30 дней).
- Звонок маме: ИИ называет прививки и спрашивает, сделаны ли они.
- «Нет» — задача медсестре «Пригласить на прививку» (72 часа); если прививку отложил врач — уведомление врачу. Пропущенная прививка зону не меняет.
- «Да» — записывается со слов родителя и считается неподтверждённой, пока не придёт запись прививочного кабинета из DMED.
- Календарь составлен по данным ВОЗ и опубликованному календарю Минздрава; с действующим приказом его нужно сверить.

## Уведомления

Каждый видит свои уведомления, руководитель — все. Жёлтые и красные дублируются в Telegram: сотрудник подключает свой чат по одноразовому коду в профиле.
